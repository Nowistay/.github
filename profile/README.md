# Nowistay

Nowistay is a PMS and channel manager for vacation rentals, with an autonomous AI co-host built in, for 1 to 100+ properties.

- **AI co-host:** answers guests on Airbnb, Booking.com, Expedia, WhatsApp and email, 24/7, in 90+ languages, and alerts the host only when a human is needed.
- **Channel manager:** rates, availability and bookings in sync across Airbnb, Booking.com, Expedia, Vrbo and Agoda.
- **Also included:** AI Pricing, digital welcome guide, cleaning and team missions, smart locks, direct booking with 0% commission.

## Use Nowistay from ChatGPT and Claude

Nowistay runs a public MCP server, so you can check bookings, change prices, answer guests and plan missions from an AI assistant.

- **Claude:** the [Nowistay connector](https://claude.ai/directory/connectors/nowistay) in the Claude directory, and the [Nowistay plugin for Claude](https://github.com/Nowistay/claude)
- **ChatGPT:** the [Nowistay plugin for ChatGPT](https://chatgpt.com/plugins/nowistay)
- **Other MCP clients:** `https://api.nowistay.com/mcp`, see the [setup guide](https://www.nowistay.com/help/how-to-connect-chatgpt-claude-to-nowistay-mcp)
